# Glossary Weekendje weg

| Woord | Betekenis | Niet te verwarren met |
|---|---|---|
| Weekendje weg | De installeerbare webapp waarmee een groep één weekend per jaar plant, voorbereidt en afrekent | De Google Sheet waarin de gegevens staan |
| Groep | Vaste set leden met één eigen Google Sheet | Editie |
| Lid | Persoon in een groep, met voornaam en woonplaats | Deelnemer |
| Editie | Eén weekend weg van een groep, meestal per jaar | Weekend (als datum) |
| Deelnemer | Lid dat aan een editie meedoet en een persoonlijke link heeft | Lid |
| Organisator | Deelnemer die een editie regelt, met een beheerlink. Een editie heeft er één of twee | Eigenaar |
| Eigenaar | Degene op wiens Google-account de Sheet staat; zet de groep op en kan beheer herstellen | Organisator |
| Persoonlijke link | Link per deelnemer per editie met een geheime code achter het #-teken | Beheerlink |
| Pincode | Zes cijfers die bij een persoonlijke link horen en apart worden verstuurd | Beheerwachtwoord |
| Beheerlink | Link waarmee een organisator na zijn wachtwoord de editie beheert | Persoonlijke link |
| Setupcode | Eenmalige code uit het Sheet-menu waarmee de eigenaar de groep in de app opzet | Pincode |
| Doorgeefluik | Het Apps Script in de Sheet dat verzoeken van de app controleert en uitvoert | Voorkant |
| Voorkant | De statische webapp op GitHub Pages, gelijk voor alle groepen | Doorgeefluik |
| Stap | Een van de vaste fasen van een editie: Invullen, Overzicht, Accommodatie, Voorbereiding, Weekend, Afrekenen, Afgerond | Bouwfase |
| Stappenbalk | Procesindicatie bovenin met alle stappen en hun verwachte datum | Menu |
| Bouwfase | Eén Claude Code-sessie uit `03-fasen.md` | Stap |
| Weekend | Vrijdag tot en met zondag, aangeduid met de datum van de vrijdag | Editie |
| Beschikbaarheid | Per weekend ja, misschien, nee of leeg (niet ingevuld) | Voorkeursmaand |
| Voorkeursmaand | Maand die de organisator uitlicht in de kalender, standaard april, mei, september, oktober | Beschikbaarheid |
| Voorkeursdatum | Het weekend dat bovenaan staat in de rangorde van het overlapoverzicht | Vastgelegde datum |
| Vastgelegde datum | Het weekend dat de organisator kiest | Voorkeursdatum |
| Overlapoverzicht | Samenvatting zonder namen van alle beschikbaarheid, zichtbaar na vrijgave | Detailoverzicht |
| Detailoverzicht | Alle antwoorden per persoon, alleen voor de organisator | Overlapoverzicht |
| Blok | Onderdeel van het invulformulier, vast of door de organisator aan te zetten | Vraag |
| Eigen vraag | Vraag die de organisator per editie toevoegt | Blok |
| Schijf | Bedragklasse in het budget: €50 voor verblijf, €100 voor het hele weekend | Bandbreedte |
| Bandbreedte | Laagste en hoogste gekozen schijf, zonder namen | Schijf |
| Deelvorm | Hoe accommodaties gedeeld worden: ter informatie, stemronde of geboekt | Stap |
| Item | Iets op de lijst wie neemt wat mee of de boodschappenlijst | Claim |
| Claim | Regel "ik neem dit mee" van één persoon bij één item | Item |
| Uit eigen keuken | Items die je van huis meeneemt in plaats van ze te kopen | Spullen |
| Spullen | Items die niet gekocht worden, zoals spellen of een speaker | Uit eigen keuken |
| Boodschappenlijst | Alle eetbare items zonder claim, op supermarktvolgorde | Wie neemt wat mee |
| Definitief | Status van de boodschappenlijst waarna niets meer kan worden toegevoegd | Afgevinkt |
| Afgevinkt | Product dat tijdens het boodschappen doen in het mandje ligt | Definitief |
| Kookbeurt | Een maaltijd met één of meer koks | Programmapunt |
| Programmapunt | Onderdeel van de tijdlijn van het weekend, met tijd en eventueel adres | Kookbeurt |
| Uitgave | Bedrag dat één deelnemer heeft betaald, met een verdeling | Ontvangst |
| Ontvangst | Bedrag dat één deelnemer heeft ontvangen voor de groep, zoals borg of potgeld | Uitgave |
| Verdeling | Wie welk deel van een uitgave of ontvangst draagt: gelijk, aandeel of bedrag | Afrekening |
| Aandeel | Tellertje per persoon in een verdeling, standaard 1 | Bedrag per persoon |
| Restcent | Het deel dat bij afronden overblijft; gaat naar de betaler | |
| Saldo | Wat iemand per saldo tegoed heeft (plus) of moet betalen (min) | Afrekening |
| Afrekening | Voorstel met zo min mogelijk overschrijvingen om alle saldi op nul te krijgen | Betaling |
| Betaling | Overschrijving tussen twee deelnemers, als betaald gemarkeerd | Uitgave |
| Afgehaakt | Deelnemer die niet meer meegaat maar betaalt voor wat al met hem gedeeld is | Niet ingevuld |
| Rondleiding | Uitleg bij het eerste gebruik op een apparaat, inclusief installeren | |
